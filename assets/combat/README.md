# 星界試煉戰鬥動作素材

正式戰鬥使用正常比例角色與魔物。Q 版步行圖只用於探索地圖。此目錄有目前公開可出戰的 11 名角色、五種 1–15 關試煉魔物、五套已建檔角色造型，以及 1.2–1.6 角色薇珂、赫洛、蕾娜、艾洛娜、艾妲、梅芙、羅薇恩的動作圖。薇珂以測量桿與潮汐脈衝削防；赫洛以橋錘與屏障護衛；蕾娜以雙匕首突刺；艾洛娜以外勤測量標記支援；艾妲轉動鐘盤淨化並施放護盾；梅芙以索引筆和書頁裁切敵方狀態；羅薇恩展開雙人工程護盾並承擔傷害。1.2–1.6 角色目前尚未對一般玩家開放。

每張 WebP 是 4 欄 × 3 列、共 12 個姿勢：第一列待機／備戰／預備／移位，第二列專屬招式的起手／出手／命中／收勢，第三列防守／受擊／踉蹌／退場。角色動作按 `src/data.js` 的技能與既有卡面設計；魔物動作按原始圖鑑立繪設計。素材由內建 imagegen 參照現有角色卡面、造型圖與魔物圖鑑生成，再清除格位外的零碎像素並壓縮為保留透明度的 WebP。

`src/player-app.js` 在戰場上同時顯示雙方全員：我方前排位於右上／右下，後排位於左上／左下，怪物由上往下排列。戰鬥時間線只讓行動者與受影響者切換攻擊、受擊或防守姿勢；下方編隊卡保留原本的角色與怪物立繪。裝備 `*-new.png` 造型的五名角色使用 `*-skin-normal-actions-v2.webp`；其他未建動作圖的造型會使用其正常比例造型立繪，避免顯示錯誤服裝。`styles.css` 控制逐格播放和降低動態效果模式。

輸出品質限制：圖像生成的逐格姿勢仍需要人工逐幀驗收；這是 2D 逐格戰鬥演出，沒有骨架動畫或逐像素碰撞判定。
