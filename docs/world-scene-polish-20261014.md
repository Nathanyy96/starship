# 大世界場景整合與演出

沿用既有高畫質手繪地圖、角色身分及Q版素材，將第一大版本探索改成以場景為主的遊戲畫面。

## 已完成

- 場景內HUD：區域名稱、目前旅程、沿路估算步數、即時小地圖，顯示角色、NPC、出口、路線及鏡頭範圍。
- 任務與傳送設定收進「地圖／傳送」面板；開啟時停止方向鍵移動，傳送後收起並回到場景。既有11個傳送點及啟用紀錄保留。
- 加入平滑跟隨鏡頭、Shift／觸控跑步切換，以及桌機全螢幕模式。
- 村內莉亞、雷恩、伊薩爾；城內米菈、老瓦克、賽芙拉；山腰驛站岑霧、西岸穆莎、東岸珂芮妲、鐘庭外庭溫藍。全部使用既有Q版素材；按腳下位置排序，包含地面陰影、待機起伏，雷恩與米菈有小範圍巡走。
- NPC可進行獨立日常交談，主線附近仍優先觸發當前主線。日常交談不推進主線、發獎或跳過劇情。正式已發佈故事文字完整保留，顯示於場景內旁白對話窗；旁白不冒用NPC說話者身分。
- 風中落葉與光點、村莊火場微光、區域進入提示與畫面銜接。減少動態效果偏好會關閉粒子、巡走、鏡頭緩動及過場動畫。
- 圖面興趣點與出口改為不同符號，靠近才顯示名稱。鐘庭使用特殊連結／局部圖標示，不宣稱與內陸共用羅盤方位。
- 地圖載入提示、失敗後可見錯誤與回復操作；地圖及NPC圖像按所在區域載入。

## 驗證

全套148項通過，9項既有略過，0失敗。檢查NPC素材存在、站位可達、巡走保持在路面、日常交談不改變劇情進度；原有路網、碰撞、傳送、帳號隔離與故事全文測試保持通過。

獨立試玩頁 `/first-major-terrain-preview.html` 增加村莊火場、白鐘工坊的展示起點，供直接檢查人物互動；此選項只在展示頁，不是正式遊戲的免費傳送入口。

視覺驗收：桌機與390×844手機已檢查場景、NPC、對話窗及地圖／傳送面板，沒有橫向溢出或前端錯誤。沿用原有深綠、暖金、象牙色與手繪美術，未替換既有全站設計系統。
