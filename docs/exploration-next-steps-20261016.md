# 探索玩法：道路、尋寶與非試煉活動

## 這次已落地

- 道路：移除獸靈之村、迴音谷、西岸聚落與洛汀港四處相疊或繞回的支路；半透明路緣與日照亮面先合成一次，再覆到路口，避免交叉處重複變亮。
- 發現感：自由探索介面顯示本區已調查地點數；未調查與已調查的地面標記顏色不同，首次調查也有獨立回饋。

## 參考與取捨

- [《薩爾達傳說：曠野之息》官方探索指南](https://zelda.nintendo.com/breath-of-the-wild/assets/pdfs/ExplorersGuide.pdf)將寶箱分散在敵人據點、神廟角落與地形祕處。適合借用「不同發現方式」，不照搬關卡或美術。
- [《Minecraft》考古更新](https://www.minecraft.net/en-us/article/trails---tales-update-now-available-bedrock)讓地點線索、輕量操作與獨特材料相連。適合本作的遺構與舊渡台，能讓尋寶不只是按一次互動鍵。
- [《No Man's Sky》遠征更新](https://www.nomanssky.com/expeditions-update/)以可任意順序完成的里程碑，搭配清楚的探索統計與地點標記。適合本作已存在的 24 張地圖和調查點，但不宜把所有獎勵綁在重複刷取上。
- [《Factorio》地形設計紀錄](https://www.factorio.com/blog/post/fff-401)使道路和樹木、懸崖、水域共用淨空規則。後續新增寶箱時，也要沿用可行走路徑與障礙物檢查，避免看得到卻摸不到。

## 下一版優先做：固定尋寶點

先在村外、南驛田間、迴音谷、遺構、西岸與洛汀港各放一處固定寶箱。每處有地形或居民留下的線索，玩家從主路走一小段可通行的支路找到寶箱；城鎮中心只放生活相關的小型藏物，不放與比例不合的大箱。

寶箱必須有穩定 ID、地圖座標、互動範圍、獎勵表與帳號層領取紀錄。開箱請求由伺服器核對 ID 並原子寫入獎勵與已領狀態；重送請求只回傳「已領取」。先使用現有星砂、角色經驗與已定義的突破材料，獎勵值在經濟測試後決定。探索畫面只在伺服器確認後把箱子畫成開啟狀態。地圖位置與路線要經 `passable`、`planWalk`、實際鍵盤移動及桌面／手機畫面檢查。

## 除了試煉的三種玩法

1. **線索尋寶**：從 NPC、路標、地圖註記取得提示，走到對應地形找一次性寶箱。核心是觀察與移動，不要求戰鬥。
2. **遺構考察**：按環境線索調查數個構件，拼出地方故事與材料配方；可以做成短流程，不必建新副本。
3. **商路委託**：在已開通的城鎮之間送物或尋找失物，使用現有道路與傳送點，但第一次必須實際走到地點；報酬依路線而非戰力計算。

順序建議：先做固定尋寶點與可見的探索紀錄，再做遺構考察；商路委託等道路方位與城鎮內容穩定後加入。
