# 技能升級預留與裝備秘境

作者確認：技能升級現在不開放；每次裝備掉落為5–8件，不是整套。

技能升級：預留普通攻擊、特殊技能、大招各自培養的方向。等舊角色的同養成實戰表現確實落後，再依角色機制評估優先開放；不預設全角色同步提升、不直接借用其他遊戲倍率。等級上限、材料、費用、倍率、命座互動與開放角色均待設計／測試。現階段不提供按鈕、扣費API、材料掉落或戰鬥加成，技能CD與能量機制不因此改變。

裝備秘境：獨立於Boss、試煉及100層塔。Boss只掉原有突破材料與經驗，不再掉裝備，已持有裝備保留。

每日體力100，採伺服器台北時間00:00補滿100，不累加、不隨版本刷新，不接受客戶端日期。成功結算消耗10點，掉落5／6／7／8件的機率各25%；失敗或超時不扣體力、不掉裝備。每天最多10次成功結算，合計50–80件。

三個獨立難度沿用現有三檔機率：入門普通65%／稀有28%／珍藏7%；進階45%／40%／15%；高階25%／50%／25%。每件獨立抽稀有度、六部位與三套裝；可能重複，不保證全套或每種稀有度必出。掉落均0級，最高強化20級；神話、傳說仍未開放。

不變條件：體力0–100、同一結算不重複扣費／發獎、重登與跨主機保存、午夜只補滿一次、切換角色／帳號不串資料。秘境掉落與Boss材料次數、試煉次數互不影響。技能升級保持關閉。

狀態：本機實作與隔離驗證完成；正式版本及部署結果以07及本機發布結果為準。

工程驗證：現行測試132通過／10略過；獨立Postgres schema跨實例同時結算只有一個成功，重啟後體力與掉落保留，1項通過。午夜補滿、不累加、10次耗盡、重送／錯誤資料拒絕、失敗及超時不扣皆有覆蓋。技能升級API不存在，請求404且角色培養／資源不變。
