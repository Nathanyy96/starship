# 第三至第五大版本角色關係規劃

來源：遊戲角色資料中的未來角色關係規劃；2026-10-07 完整移存。這是設計參考，不表示角色已進入正式卡池。

## 大版本敘事重點

- 3.0–3.5：從獸靈之村的共同生活延伸到不讓任何人永遠成為唯一中心；霽羅、蘿堤亞與洛恩各自代表測線、聲音與火路的不同選擇。
- 4.0–4.5：北境神話意象從傳說變成生活規則；奧蕾雅、凱嵐與伊萊拉分別把光、火與律法寫成可共同修改的制度。
- 5.0–5.5：瑟蕾雅面對母親與世界中心的最後選擇；維斯妲、伊芮恩與達莉雅讓空位、通路和交班成為她真正能留下的答案。
