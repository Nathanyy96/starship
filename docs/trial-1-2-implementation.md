# 1.2 試煉實作驗收

- 試煉僅 1–15 關，每關每版本三次挑戰；超時不扣次數。
- 第 10 關為四名滿級四星、平均 C3 的終局參考。怪物三隻，依速度各自行動。
- 第 11–15 關為上下半場；每半場可派 1–4 名已取得角色，兩邊不可重複。
- 每半場三隻魔物；援獸可被擊倒，減少敵方後續行動。兩半皆通過才發一次獎勵。
- 1–15 使用實際魔物 WebP，逐行動顯示 HP、護盾、出手和戰鬥事件。上下半場依序播放。
- 敵方技能由各自 traitKey 決定，援獸不繼承首領技能。
- 已實作晶殼、護區轉移反擊、織網延後冷卻、折射增益、換獵、三次巢群回護、預充雙擊和雙相換相。
- 11–15 獎勵補齊；作者試玩預選第 10 關，沒有第 16 關以後的入口。

## 平衡取樣

滿級 C3，QWER 上半場、梅芙／赫洛／艾洛娜／瑟蕾雅下半場，30 個固定種子：第 10–15 關均可通關；平均合計回合約 39、32、30、46、37、39。部分角色會退場。取樣只代表這兩套編成，其他隊伍仍可能需要調整或不同對策；沒有把通關率當作所有隊伍的保證。
