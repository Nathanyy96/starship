# 探索道路、轉場與傳送修訂（2026-10-15）

依作者提供的人物／道路比例參考，改為可讀的俯視地形探索層。此輪本地完成，未部署。

## 道路與碰撞

- 探索地面改由同一份可行走資料繪出；背景總覽插畫留在查閱地圖，不再將插畫中任意地面當作隱藏碰撞線。
- 新增像素地面材質與透明物件圖集：草地、土路、石路、木地板、森林地面、水面、岩壁，以及樹、灌木、房屋、遺構和貨物。
- 道路半寬至少 48 地圖單位（既有村路約 48–62）；人物高度由約 104 降至 44，並調整鏡頭，使路寬與角色比例更清楚。
- 樹木、房屋及障礙物的完整佔地只放在不可行走區，不蓋住可走道路。移動仍檢查腳部範圍，避免由拐角切入障礙。
- 南驛祭壇新增可行走平台與右側階梯，封閉原本左側穿牆捷徑。平台、階梯與碰撞共用資料。

## 連續區域

道路出口由靠近按 E 改為步行進入出口範圍後自動換圖，保留 E 作替代操作。落地後不會立即反彈回上一張圖。

1. 獸靈之村西口 → 西行兩日商路 → 白鐘城。
2. 獸靈之村南側 → 南驛山谷 → 下游商路 → 洛汀港陸路港區。
3. 白鐘北門 → 三日北行商路 → 霧橋 → 山腰驛站／迴音谷；其他既有相鄰出口沿用同一轉場方式。

世界地圖頁新增「自由探索・連續地圖」。自由探索存檔與各幕劇情位置分開，不能因此標記劇情完成或領獎。從舊村莊探索向西／南走也能接入連續區域。洛汀港在本輪作者指定下新增陸路探索接段；未開放的第二版正文、海上航路與版本獎勵沒有因此開放。河運步程仍以既有設定為準，不由局部圖距離換算。

## 對話

新增 `src/world-story-dialogue.js`，逐段登錄 1.0 第二至五幕、1.1 五幕的發言者，將直接台詞與敘述分開顯示。主角／雷恩等角色顯示本人名字與頭像；敘述顯示「旁白」並隱藏人物頭像。補正第一幕未識別的一句主角台詞。引用詞語保留為敘述，不當作角色正在說話。

十幕原文與標點順序保持完整；分卡後為 64 段、1,170 張文字卡。十二個互動步驟與正式帳號保存／領獎流程不變。

## 圖上傳送

「地圖／傳送」直接打開區域圖；點選區域後，顯示該區可走地形及傳送點。亮色菱形可直接點擊傳送，灰色為尚未啟用。室內及工坊子區域從對應父區域入口查看。舊文字選單不再顯示在遊玩流程中。

本地 file:// 模式不將地圖 canvas 匯出成資料網址，避免瀏覽器對本地圖像的 canvas 安全限制導致傳送圖無法開啟。
