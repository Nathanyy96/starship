# 1.1 抽卡機率定稿

依作者 2026-10-08 明確指示調整，隨 1.1 開放生效；公開 1.0 暫沿用原規則。

| 距離上次四星的抽數 | 1.1 四星機率 |
| --- | --- |
| 1–20 | 0% |
| 21–30 | 10% |
| 31–40 | 15% |
| 41–49 | `0.15 + 0.85 × (2^((抽數−40)/10) − 1)` |
| 50 | 100%，硬保底 |

41 抽約 21.10%，49 抽約 88.62%。出四星後重新計數。單抽 160 星砂、十連 1,600 星砂；十連依序進行十次相同判定。

限定四星選定角色機率仍為 55%，歪掉後下一隻四星必為選定角色。保底計數、精選保證、帳號資源及角色收藏保留，無追溯扣除。其他抽卡補償、返還、兌換與角色數值未修改。

從零保底起精確計算：平均 28.5941 抽取得四星，長期綜合率約 3.4972%；30 抽內出四星 65.1322%，40 抽內 93.1354%。無精選保證開始，平均 41.4615 抽取得選定角色（不含返還與兌換）。原规则平均 26.1263 抽、30 抽內 80.3126%。

同一核心用於伺服器與網頁機率顯示；測試逐一核對全 50 抽、分段邊界、指數公式、50 抽硬保底，並在 1.0／1.1 兩種發布設定回歸。
