# 大世界主畫面與帳號位置存檔（2026-10-15）

## 使用者確認的方向

大世界探索與場景互動成為遊戲主要玩法。取消原本大廳選單頁，登入後直接進入上次退出的探索地點。新帳號直接進入南驛舊祭壇開場，立即播放既有第一段劇情；不再先經過主線選擇頁。

## 介面與操作

- 上方常駐三個繪製的 SVG 小圖示：抽卡、試煉、選單；左方羅盤可從功能頁回到大世界。
- 角色培養、星伴培育、主線旅程、商店、突破首領、委託、迷航、世界地圖、公告與教學收在「旅途選單」。旅程獎勵、同步與帳號切換也在選單內。
- 探索場景填滿上方工具列以下的視窗，手機保留方向控制與場景互動；大廳的橫幅、功能卡片與入口選擇頁從登入流程移除。
- 選單使用原生對話框，支援 Escape、鍵盤焦點及捲動；場景暫停且清除持續按鍵。關閉後回到原位置與原對話卡。
- 功能頁、抽卡、試煉返回時恢復原探索，不重設入口，不重播正在暫停的對話。
- 主線讀取、地圖傳送、任務互動、版本獎勵與角色養成都保留既有規則；探索地圖仍可從主線之外自由走訪。

## 存檔與遷移

- 新增帳號狀態 `worldPosition`，保存場景種類、可通行座標、所在幕次與探索狀態；沿用 PostgreSQL JSON 狀態欄位，不需要刪除或重建資料表。
- 新增登入驗證的 `/api/player/world-position`，只接受探索狀態白名單並驗證地面碰撞；資源、角色數量與任務獎勵不由位置存檔更新。
- 本機先記錄，線上節流同步；離開頁面、切換帳號與視窗隱藏時補送最新位置。使用請求順序避免同次登入的舊同步覆蓋新位置。
- 網路暫時失敗時保留裝置存檔並顯示同步狀態，恢復連線後補同步。新瀏覽器登入可從帳號恢復位置。
- 舊帳號優先接續既有自由探索、村莊或開場存檔；已完成第一幕且無探索存檔者進入村莊。各帳號分開保存，切換時關閉原控制器並丟棄舊回應。
- 新帳號出現在祭壇附近的勘路點，播放第一幕原有的核對岔路段落，之後沿指引回到祭壇；正文、講者及既有插圖不改寫。
