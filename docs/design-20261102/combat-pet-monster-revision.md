# 三星角色收斂、全角色星伴搭配及魔物試煉規格

2026-11-02｜作者最新修正優先。這份為設計稿，沒有改正式遊戲、沒有跑待審新三招的戰鬥測試。

## 三星角色強度重訂

上一版三星同時有高倍率大招、淨化、分攤與保命，功能過滿；收斂如下。與原生四星相比，三星的優勢是容易取得／滿命，不是更低成本獲得相同頂級性能。角色武器不改。C0只具一項主要職責與一項有限附屬功能，C6改善本職，不增加完整第二職責。以下取代聊天上一版三星技能／命座候選，尚未寫回04A正式條目。

普攻回能20／特殊回能30仍沿用候選，三星特殊CD統一3，避免容易滿命又因CD2額外取得過多大招。

### 三星C1–C6精簡版

所有數值均改為、不是額外相加。C4之類條件只強化指定對象，不額外擴散至全隊。

測試目標而非已有結論：在相同等級／裝備／星伴、相近職責下，三星C6的長線主要職能約落在同類四星C0的75–85%候選區間；個別低成本或特定對策可有優勢，不能將所有場景硬壓相同百分比。比較包含能量、CD、目標數、有效治療、分攤、技能覆蓋，不能只比單招倍率。

## 任何角色可裝任何星伴

三星角色可裝四星星伴，四星角色可裝三星；角色與星伴原生稀有度不構成裝備限制。專屬僅最佳適配。事件判斷全部基於裝備者／裝備者創建的效果，不以角色姓名硬鎖。星伴基礎屬性所有裝備者均生效；條件技能沒有相應事件時不觸發，不偷偷改成別的事件。

各星伴的傷害元素獨立記錄；不能替裝備者偽造一次元素主動命中、替菲芮填元素、替奧薇拉啟毒。星伴傷害／補盾／治療不幫角色回能、不引發角色或其他星伴遞迴。

### 跨角色事件定義

- 白貓：裝備者創建的敵方可攻擊標記，被其他隊友主動命中才觸發；不要求裝備者是瑟蕾雅。雷恩瞄準、Hina燕音、Magenta灼印、奧薇拉蛇印可納入候選標記類型，單純降攻／降防不是標記。
- 小狗：裝備者施加的護盾實際吸收敵傷才觸發；沒有盾技能的角色仍有基礎屬性，不憑空給盾觸發。
- 狐狸：裝備者擁有灼印且交鳴發生才觸發，或裝備者的主動燕傷實際引發交鳴才觸發；這兩個方向同回合共用一次額度。三星蕾娜的烈攻擊不是灼印，不能單靠烈元素啟動。
- 灰貓：裝備者主動燕傷引發交鳴才觸發；岑霧／雷恩可用，但需要隊友提供灼印；非燕角色不靠星伴追加燕傷自啟動。
- 倉鼠：按裝備者實際站位；後排定期單補所有角色可用，前排治療增幅只增強裝備者本來就有的治療。雷恩站前排不會憑空學會補血。
- 潮紋魟：裝備者主動技能成功施加降防才觸發；受到降防目標的隊友不冒領施加者身份。
- 岩背獾：裝備者實際承接護衛分攤傷害才觸發；雷恩、芮妲、赫洛、伊薩爾如新稿無分攤則不因職稱觸發。
- 水母：裝備者自己擁有的持續召喚／法器協同命中才觸發；瞬間影靈普攻不是留場召喚，榆安伴光可依召喚協同標籤觸發。沒有形態的裝備者採通用單體追加小傷害，不限定艾洛娜；治療分支只由明確救援形態開啟。
- 星紋貓：裝備者實際移除負面才觸發；瑪洛、莉亞等角色需新稿確實有淨化，治療本身不算淨化。
- 夢眼蛾：裝備者造成敵技延後才觸發；免疫降級分支必須真的嘗試延技，普通攻擊不能刷免疫補償。
- 銀角鹿：裝備者技能實際支付生命才觸發；敵傷、分攤、自身已滿血的「治療消耗」都不算生命支付。
- 琉璃蝶：裝備者創建的命中支援被隊友消耗才觸發，不冒領全隊其他來源的支援。
- 月背熊：裝備者創建的盾在敵方群攻中實際吸收傷害才觸發；芮妲單盾也可用，全隊共用一次額度。
- 粉影貂：裝備者成功驅散敵方增益才觸發，淨化隊友負面不是驅散。
- 潮音海豹：裝備者創建的持續區域造成傷害才觸發；蛇毒是目標狀態，不算區域。
- 風羽燕：裝備者的主動命中實際完成一組隊伍順風元素才觸發；隊伍需有菲芮開啟順風，但裝備者可為任何參與完成元素組的角色，不是限定菲芮本人。
- 羽冠鴿：裝備者成功給隊友攻擊增益才觸發；易傷／降防不是攻擊增益。
- 潮紋螈：裝備者擁有的蛇毒實際跳傷才觸發；沒有蛇毒來源的角色可裝備但不憑空上毒。未來角色若有相容蛇毒機制亦可觸發。

### 組合驗證範圍

26名角色×25隻星伴（7既有三星＋18四星候選）＝650組；艾洛娜另測兩形態，合計至少675個角色形態／星伴配置。每組交叉測星伴Lv.1／25、C0／C4，以及角色C0／C6；不能只測原配。未生成原圖／未開池的第二版星伴只在合成設計資料中測，不開放給正式玩家。

每組須區分：可裝備且技能自然觸發、需隊友／站位／敵人狀態才觸發、可裝備但本體沒有對應事件。最後一種不是錯誤，但UI應明示條件，不能顯示技能全開。

檢查：基礎屬性、有效觸發與不應觸發、存檔重登、裝備轉移、切帳號、同一星伴不可同時佔兩人、四人星伴疊加、低血與滿血、敵人免疫、過期標記、多段／追擊、不復活／不返能／不遞迴。全組合實戰測試需等三招設計審閱後執行；本次僅生成規格，未宣稱650組已驗證。

## 魔物到試煉的編組

新魔物種族不按國家元素綁定；陸海空是生態與招式標籤，不構成某武器完全打不到的硬免疫。近戰可透過戰鬥演出處理俯衝落地／岸邊交鋒，海戰不要求所有角色突然會游泳；場景不符時採試煉投影編組，不反推原世界海怪能在街道走路。

- 1–10層：兩隻低階為主，單體／小群傷；如草脊跳獸＋麥穗啃甲，鹽灘彈蟹＋潮牙獵魚。沒有多重控制、連續召援或無預告重擊。
- 11–24層：兩低一中；如桑枝黏蛛＋草脊跳獸＋攀枝獵猿，讓玩家理解緩速與集火；礁鳴海葵＋兩隻潮牙獵魚，理解先打支援。
- 25層錨點：河根護獸的弱化中階試煉變體＋桑枝黏蛛＋河汀泡蛙。保護、緩速、低倍率群傷各自有解；25層變體不可直接套高階Lv.70面板。以四名原生四星80等C0、初始三星星伴、六格未強化裝備校準。
- 26–40層：兩中一低；如礦脈鏨獸＋廊頂懸蛛＋窯縫灰翅，穿甲預告、施法後壓力、減療，但不讓三技能同回合必定秒殺。
- 41–60層：一高一中一低；如伏礁鉗獸＋礁鳴海葵＋潮牙獵魚。先處理支援、拆盾或存大招均可行。
- 61–80層：一高兩中，開始加入有限召援／姿態首領。首領不每層出現；如種庫伏藤＋倒湖鏡鰭＋根谷搬殼獸，淨化與護衛拆解都有用。
- 81–89層：高階主體配中階支援，至少輪替群攻、護衛、驅散、減療、蓄力五類題型，不能固定使用某一隻怪當後段標準答案。
- 90–100層：首領＋中階支援為主，不堆三名完整首領。例：萬作廊複殼體＋鳴瓷聚殼（中階變體）＋廊頂懸蛛；白夜角冠＋霧翅灰鴞＋暖泉絨蠑；終層階潮雙棲王＋長階游鰻＋潮池鼓蟹。逐層數值預算上升，換題時將機制價值折算進預算，不能只因換怪讓較高層普遍更容易。

地圖區域決定候選魔物池，但試煉可以混不同地區的合理戰術投影。連續兩層不得完全相同陣容；同一主怪不得連續超過兩層；每10層至少四個不同主怪與三種戰術題型。新圖鑑先提供劇情可用素材，不能直接把新物種的襲擊或居民死亡寫成02已發生事件。
