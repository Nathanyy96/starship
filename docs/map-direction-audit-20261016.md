# 可玩地圖道路與方位核對（2026-10-16）

核對範圍：24 張可玩地圖、48 個地區及建築出口。方位以遊戲內區域圖的北上座標為準；室內入口及特殊傳送不按地表羅盤判斷。

另外 11 張可玩圖為工坊近端／對岸、迴音谷舊渡台及旅店、醫療屋、觀測分會、驛務室等建築或局部場景；入口與回程接點已逐一實走。鐘庭窗口不表示地理相鄰；斷橋東岸的回程需沿山路繞過河谷，因此不是朝斷橋西岸直行。

本輪修正白鐘城至南驛的出口，補城南河橋及南驛北側道路；南驛返獸靈之村改接東北林路；迴音谷返霧橋改接西側道路，預設起點也移到該入口附近。移開南驛兩處與新道路相交的菜圃景物，於工坊對岸、舊渡台、遺構與斷橋西岸補少量路旁景物。城南河道與沿河街道錯開，木橋只覆蓋真正的過河路段。

驗證：24 張地圖桌面及手機擷取無頁面或素材錯誤；48 個出口均用瀏覽器方向鍵走到並完成預期轉場；224 項測試中 215 通過、9 項既有略過、0 失敗。`test/terrain-navigation.test.js` 新增區域圖方位及雙向接點檢查。
