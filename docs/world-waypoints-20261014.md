# 大世界傳送點

目前第一大版本設有11個固定傳送點：10個區域的入口／安全落腳處，以及白鐘城中央廣場。

- 首次必須親自走到傳送點56地圖單位內，按「啟用附近傳送點」。
- 啟用後可從傳送目的地列表隨時免費返回，不要求站在另一座傳送點旁。
- 未啟用的目的地顯示鎖定，不能直接選擇；沒有其他大版本或海洋傳送點。
- 劇情對話及主線保存期間停用傳送，避免跳過場景。傳送不變更故事索引、完成紀錄、獎勵或調查紀錄。
- 既有探索存檔可直接遷移，首次無已啟用點。啟用紀錄依帳號保存在此瀏覽器，第二／三幕共用；目前不提供跨瀏覽器或跨裝置同步。
- 試玩頁的啟用紀錄僅存在該次頁面記憶體，不寫入正式帳號；正式遊戲可在重開瀏覽器後繼續使用。

後續版本可沿用waypoints登錄資料；加入固定ID、所屬地圖、名稱及安全座標即可，仍須由版本的區域開放規則允許傳送。

驗證包含首次啟用範圍、未啟用拒絕傳送、全部落點安全且可實走抵達、跨幕共用、帳號切換隔離、存檔過濾與對話期間阻擋。瀏覽器實測桌機與390px手機的啟用、目的地選擇與跨區返回。
