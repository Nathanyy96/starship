# 角色／星伴召集改為含培養素材

來源：作者2026-11-02確認兩類卡池都不能每抽必出角色／星伴，避免過快取得及滿命。

先判定四星；未出四星時，20%出三星，80%出培養素材。這是條件機率，不是固定每五抽一隻，也沒有十連三星保證。每抽均單獨判定，十連可全為素材，或在極低機率下出多張四星。

- 角色：四星基礎0.6%×1.05^(目前四星抽數−1)，70抽保底。非四星20%抽三星角色，80%給120角色經驗，不額外返還星砂。首抽總機率為四星0.6%、三星19.88%、素材79.52%。
- 星伴：四星基礎1%×1.06^(目前四星抽數−1)，50抽保底。非四星20%從七隻三星等機率取得，80%給星伴飼料×1。首抽總機率為四星1%、三星19.8%、素材79.2%。

三星與素材都累積四星計數，不清歪後保證；出四星才歸零。兩池各自保存計數，55%心願與歪後下一四星保證維持。角色池不出星伴，星伴池不出角色；兩池都可出各自培養素材。

素材不解鎖收藏、不提升命座、不生成星伴印記；星伴素材結果明確標示「未獲得星伴」，不畫成三星寵物。歷史記錄保存每抽結果，舊星伴紀錄相容為pet類型。

本次為1.1.2內的平衡修正，build=gacha-materials-20261102；不改appVersion、試煉／塔週期、體力日期、補償週期，不重置既有抽數／收藏，也不刪除先前取得的角色或星伴。

不變條件：素材與寵物混合十連不沿用前一抽petId；十個結果與十次扣費對應；三星／素材不影響其他池保底；四星硬保底不被素材覆蓋；歷史記錄重登仍完整；並行或重送不能重複扣費／發獎。
