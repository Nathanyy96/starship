# 玩家介面

範圍：`index.html` 的登入、大廳與所有玩家玩法畫面。模式：Operate，並讓遊戲世界在每個畫面保持可感知。

## Direction contract

THESIS: 玩家從一座星艦導航艙進入各區域；共同導航像航行目的地，而不是八張同型功能卡。保留原有玩法名稱、文案與規則。

OWN-WORLD: 深藍船艙底色、暖金導航標記、青色狀態光與既有場景圖像。大面積場景承載情緒，精確的資訊欄承載操作。控制項使用清楚的實體輪廓，選中狀態以光帶和實色表示。

STORY: 登入後看到旅程進度、繼續劇情及所有目的地。進入玩法後，固定導覽與返回大廳的語意一致，資源與狀態隨時可辨。

FIRST VIEWPORT: 頂端是遊戲身份與帳號；其下是常駐目的地導覽。大廳以場景橫幅承載名稱、進度和繼續動作，玩法入口以不等寬航線排列。手機上導覽可水平滑動，內容單欄閱讀，不出現頁面橫向溢出。

FORM: 星艦導航艙，概念種子 `f8ab0be1` 的第三個本土方向，經使用者選定。標誌性互動是目的地切換時導覽狀態同步更新，並以短暫的內容入場動態表現抵達。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
